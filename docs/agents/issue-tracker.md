# Issue Tracker: GitHub

This repo tracks issues in **GitHub Issues** at `https://github.com/Yuji-it777/maison-tislit/issues`.

## Workflow

- Use the `gh` CLI for all issue operations (`gh issue create`, `gh issue list`, `gh issue view`, `gh issue edit`, `gh issue close`).
- Issue references in commits: `#123`, `Closes #45`, `Fixes #67`.
- PRs are **not** automatically added to the triage queue (`prs_as_request_surface: false`).
- Labels follow the triage vocabulary in `docs/agents/triage-labels.md`.
